Configure a runtime and copy the generic example into a claimed workspace first. Provide your own room before assembly. The following commands resume a prepared run through the selected stage, including unfinished predecessors; only stages enabled by its recipe can run.

  1. motion

    Generate approximate actions and root paths

    bash tools/indoor execute /path/to/prepared-run --until motion

    Setup

  2. resample

    Resample rotations while preserving requested duration

    bash tools/indoor execute /path/to/prepared-run --until resample

    Setup

  3. skin

    Export the fixed-topology SMPL-X body mesh

    bash tools/indoor execute /path/to/prepared-run --until skin

    Setup

  4. layout_inspection

    Render and review matched source/room layout evidence

    bash tools/indoor execute /path/to/prepared-run --until layout_inspection

    Setup

  5. assemble

    Place the body and assets in an editable room copy

    bash tools/indoor execute /path/to/prepared-run --until assemble

    Setup

  6. verify

    Check saved geometry and synthetic projection artifacts

    bash tools/indoor execute /path/to/prepared-run --until verify

    Setup

  7. render

    Render the selected camera and frame range

    bash tools/indoor execute /path/to/prepared-run --until render

    Setup

  8. video

    Encode and fully decode the rendered sequence

    bash tools/indoor execute /path/to/prepared-run --until video

    Setup
